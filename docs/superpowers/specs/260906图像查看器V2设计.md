# ImageViewer V2 设计

## 目标

在 V1 查看、缩放、目录缩略图、自定义标题栏和实时预处理基础上，补齐工业图像日常分析、对比、保存与大图浏览能力。功能默认不干扰看图主流程，分析和预处理均可显隐。

## 功能范围

### 像素与 ROI 分析

- 新增默认隐藏的“像素与 ROI 分析”停靠面板，快捷键 `Ctrl+I`。
- 鼠标移动时显示当前展示图像的坐标、RGB、灰度、HSV、Lab 数值。
- 按住 `Shift` 后左键拖动选择矩形 ROI；面板显示范围、像素数、各通道最小值、最大值、均值和标准差。
- 显示 256 档灰度直方图。ROI 统计在工作线程执行，以代次号丢弃过期结果，避免阻塞 UI。

### 原图/处理图对比

- 采用单视图竖向分割对比：左侧原图、右侧处理图，共用一套缩放和平移坐标，不产生双视图同步漂移。
- 分割线可拖动；无有效处理结果时对比功能禁用。

### 结果与预设

- 可将当前展示结果另存为 PNG/JPEG/BMP/TIFF/WebP，由扩展名选择编码器。
- 预处理参数可保存为版本化 JSON，并可从 JSON 载入。载入时校验并钳制范围，异常文件不改变当前设置。

### 缓存与大图

- 当前图加载后，在后台预加载前后各两张邻图；采用受限内存缓存，容量 384 MiB，按最近使用自动淘汰。
- 缩略图磁盘缓存位于 Qt 标准缓存目录，以规范路径、文件大小、修改时间和缩略图尺寸生成键；上限 256 MiB，按最久未使用清理。
- 视图为当前图异步生成多级二分辨率显示金字塔；缩小时选择合适层级，减少超大原图反复全分辨率采样。高倍率自动回到原始层并保持像素格准确。

## 性能与线程边界

- UI 线程只更新控件、场景和最终结果；图像处理、ROI 统计、邻图加载、缩略图生成、金字塔构建均在工作线程。
- 异步结果均使用图像/请求代次校验，过期结果不得覆盖新图。
- 缓存有硬上限，不允许目录浏览导致内存或磁盘无限累加。

## 非目标与限制

- 本版显示金字塔基于已解码的当前图构建，可显著降低缩小渲染采样成本，但不等同于 TIFF/BigTIFF 等格式的编码器级按瓦片局部解码。
- 不加入编辑历史、批处理、标注文件格式和插件系统，避免把查看器扩张为图像编辑器。
