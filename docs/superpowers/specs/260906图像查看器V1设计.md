# 图像查看器 V1 设计

## 1. 目标与范围

在现有 C++17、Qt 5.14.2、OpenCV 4.5.5、Visual Studio 2019 工程基础上，建设一个面向日常看图与工业视觉辅助观察的本地图像查看器。V1 完成基础看图、目录导航、自定义窗口、多语言基础和可显隐实时预处理。

V1 不引入 QML、GPU 自定义渲染或大图瓦片金字塔，不实现破坏性原图编辑。预处理结果仅用于实时预览，始终保留原图。

## 2. 总体架构

采用 Qt Widgets 模块化方案：

- `MainWindow` 负责窗口组装、文件导航状态和组件协调。
- `TitleBar` 负责无边框窗口拖动、双击最大化、最小化、最大化/还原和关闭，同时展示当前图像摘要。
- `ImageView` 负责图像渲染、缩放、平移、像素格和查看背景。
- `ThumbnailBar` 负责当前目录图像列表、缩略图和当前项高亮。
- `PreprocessPanel` 负责算子选择、参数编辑、启用/停用和一键复原。
- `ImageProcessor` 负责 OpenCV 预处理管线，不依赖 UI。
- `ImageLoader` 继续负责解码，并返回文件和像素元数据。

## 3. 主窗口与标题栏

主窗口使用 `Qt::FramelessWindowHint` 去掉 Qt/系统原生标题栏，使用自定义 `TitleBar` 代替。Windows 下通过 `nativeEvent()` 提供边缘命中测试，保留标准窗口拉伸体验。

标题栏按空间可用性展示：文件名、当前序号/目录图片数、缩放比例、图像尺寸、文件大小、像素格式/通道数、文件修改时间。过长文件名使用省略显示，完整路径放入提示文本。

## 4. 图像查看交互

- 鼠标滚轮以光标指向的图像位置为锚点连续缩放。
- 缩放比例限制在 `1%` 至 `6400%`，防止变换矩阵无界增长。
- 提供适应窗口、实际大小、适应宽度和适应高度。
- 低倍率使用平滑缩放；放大到可辨识像素的阈值后改用最近邻渲染，从 `800%` 起绘制单像素边界网格。
- 图像区背景固定为统一深灰色，缩小后不显示纯黑或透明棋盘背景。透明图像以可配置的中性底色合成预览。
- 左键或空格+左键平移，双击在适应窗口与 `100%` 之间切换。
- 图像切换时默认重新适应窗口，避免前一张图的极端缩放状态影响新图。

## 5. 目录缩略图与导航

打开单个文件后，扫描其父目录下支持的图像扩展名，按文件名的本地自然顺序排列。底部缩略图栏显示可见项附近的缩略图，当前文件有明确高亮。

缩略图在线程池中解码并缩放，通过 queued signal 回传 UI；任务带目录代次标识，切换目录后丢弃旧结果。内存缓存设置固定上限，不允许随浏览文件数无限增长。

支持缩略图点击、左右方向键、工具栏上一张/下一张。损坏文件显示占位图并给出中文错误，不导致目录导航中断。

## 6. 实时预处理

右侧 `PreprocessPanel` 默认隐藏，可通过工具栏按钮或菜单显示/隐藏。面板开启后可选择和调整：

- 亮度：线性偏移。
- 对比度：线性增益。
- Gamma：查找表实现。
- 灰度化。
- 阈值化：固定阈值和 Otsu 自动阈值。
- 通道查看：B、G、R 或灰度。
- 平滑：均值、高斯、中值。
- 锐化：Unsharp Mask。
- 边缘：Sobel、Laplacian、Canny。
- 形态学：腐蚀、膨胀、开运算、闭运算。

算子按固定顺序串行：颜色/通道、亮度对比度与 Gamma、平滑/锐化、阈值/边缘、形态学。参数变化使用约 `80 ms` 单次延迟合并，避免滑块连续触发重复处理。处理任务使用线程池，新请求用代次号使旧结果失效，UI 线程不执行 OpenCV 重处理。

关闭面板、取消总开关或点击“复原”时立即显示原图。V1 不覆盖原文件，不自动保存处理结果。

## 7. 多语言与编码

- 所有用户可见字符串均使用 `tr()` 并保持翻译上下文稳定。
- 引入 `translations/ImageViewer_zh_CN.ts` 和 `translations/ImageViewer_en_US.ts`，构建时生成 `.qm` 并部署。
- 默认跟随系统语言，菜单支持中文/英文切换，选择保存到 `QSettings`。
- 工程继续使用 UTF-8 源码和 `/source-charset:utf-8 /execution-charset:utf-8`；不再使用 `QStringLiteral`。
- 文件路径始终以 `QString` 在 Qt 内部传递；OpenCV 回退解码改为 `QFile::readAll()` + `cv::imdecode()`，避免中文路径经过本地编码丢失。

## 8. 错误处理与性能边界

- 文件不存在、解码失败、内存不足和预处理失败均返回可翻译的用户消息，并用 `qWarning()`/`qCritical()` 记录路径、图像尺寸、算子与耗时。
- 所有异步回调在使用 UI 对象前检查对象生命周期，关闭窗口时不留存可访问已销毁对象的任务。
- 不对原图做多份无界拷贝；目录列表、缩略图缓存和预处理结果都有明确的释放路径或上限。
- V1 以 4K/8K 单张图像操作流畅为目标；极大 TIFF/RAW 的瓦片解码属于后续专项。

## 9. 验收标准

1. 中英文菜单、对话框、工具提示和错误信息显示正常，中文路径图片可打开。
2. 滚轮缩放保持光标下图像位置，`800%` 及以上能明确看到像素格。
3. 图像缩小后四周是统一深灰色，无纯黑区域或棋盘格。
4. 打开目录内任一图片，底部可见其他图片缩略图，点击、键盘和工具栏均能切换。
5. 标题栏非 Qt 原生，标题信息与当前图像、缩放状态和目录序号一致。
6. 预处理面板默认隐藏；所列算子可实时预览，连续拖动参数时 UI 无明显卡死，复原后与原图一致。
7. Debug 与 Release x64 均生成 PDB；Release 保留优化并使用 `/Zi` 和 `/DEBUG`。

## 10. 待审核的后续常用功能

以下功能不进入本次 V1 实现，待审核后再分期：

- 颜色拾取器：显示坐标、RGB/HSV/Lab 和灰度值。
- 处理结果另存为与格式转换。
- 原图/处理图分割对比或左右对比。
- EXIF/图像元数据面板。
- 旋转、镜像、无损 JPEG 旋转、裁剪和尺寸调整。
- 复制图像、复制文件和复制路径到剪贴板。
- 全屏、无边框聚焦模式、幻灯片和循环导航。
- 邻图预加载、持久化缩略图缓存和大图瓦片金字塔。
- 文件变化监听、自动刷新和删除/移动文件后的稳定导航。
- 动图与多页 TIFF 帧导航。
- ICC 色彩管理、HDR 色调映射和高位深灰度图显示策略。
- 快捷键、滚轮行为、背景色、插值模式和工具栏按钮自定义。
