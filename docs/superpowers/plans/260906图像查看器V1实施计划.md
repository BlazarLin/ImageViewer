# 图像查看器 V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Qt 5.14.2/OpenCV 4.5.5 工程中完成 ImageGlass 风格的基础图像浏览、目录缩略图、自定义标题栏、多语言和可显隐实时预处理。

**Architecture:** 保留 Qt Widgets，将窗口外观、图像交互、目录导航和 OpenCV 处理拆分为独立组件。`MainWindow` 只组装组件与管理当前文件，异步结果使用代次号丢弃过时回调。

**Tech Stack:** C++17, Qt 5.14.2 Core/Gui/Widgets/Concurrent/LinguistTools, OpenCV 4.5.5, Visual Studio 2019 v142, CMake 3.20+

## Global Constraints

- 所有用户可见文本使用 `tr()`，不使用 `QStringLiteral`。
- UI 线程不执行大图 OpenCV 处理，跨线程回调使用 queued connection/安全上下文对象。
- `QImage`/`cv::Mat` 的通道顺序、位深和所有权必须显式。
- 缩略图和处理结果不得无限累加。
- Debug/Release x64 均使用 `/Zi` 并产生链接器 PDB；Release 保留优化。
- 不覆盖或修改原图文件。

- [ ] **Step 1: Write processor tests**

- [ ] **Step 2: Implement explicit conversions**

  Normalize the working image to owned `CV_8UC1`, `CV_8UC3` or `CV_8UC4`; convert BGR/RGB deliberately and never expose a `cv::Mat` that outlives its `QImage` buffer.

- [ ] **Step 3: Implement the fixed pipeline**

  Apply channel/grayscale, brightness/contrast/Gamma LUT, smoothing or unsharp mask, threshold or edge, then morphology. Return a translated error instead of throwing across the UI boundary.

- [ ] **Step 4: Implement the optional panel**

  Create a right-side panel that is hidden by default. Every variable has an initialized value; kernels are odd and bounded. A single 80 ms timer coalesces slider edits.

- [ ] **Step 5: Run work off the UI thread**

  Dispatch one immutable input/parameter snapshot with `QtConcurrent::run`; increment a generation for each request and display only the newest result.

- [ ] **Step 6: Verify and commit**

  Run processor tests and drag sliders over a 4K image while monitoring UI responsiveness. Commit as `feat: add optional realtime preprocessing`.
