# 2026-09-08 字体、RGB 直方图与开源发布准备

## 本轮结果

- 修复 Qt 5 高 DPI 缩放未启用的问题；启用高分辨率图标、保留 150% 等非整数缩放比例。全局与标题字体改为 18px，主窗口初始大小受可用屏幕约束，缩略图和面板留白同步调整。
- ROI 一次像素遍历同时生成灰度及 R/G/B 各 256 档计数。彩色图显示三个通道，灰度格式显示单通道；各通道单独标注纵轴峰值，悬停读取灰度档与精确像素数。开始新分析时清空旧统计，避免旧结果与新选区混用。
- 分析面板分为“像素与统计”“直方图”两页，图表所在滚动区保持深色主题。配图使用程序生成的 RGB 示例，不使用私人图像。
- 源码版本更新为 2.2.0（未公开发布）。重写 README；新增 MIT、第三方许可说明与基础许可原文、贡献/安全文档、更新记录、发布指南、Issue/PR 模板、编辑器与换行配置、Actions 依赖更新及 Windows CI。
- 公共依赖配置移除本机 Qt 默认路径；本机设置保留在忽略的 `cmake/Config.local.props`。支持官方 OpenCV Windows SDK 路径；显式 CMake OpenCV 配置优先于历史内置依赖。
- 新增便携 ZIP 打包：独立部署 Qt、图片插件、OpenCV 与 MSVC CRT；包含构建元数据和 SHA-256 校验文件。CI 固定外部 Action 提交与 OpenCV 4.5.5 提交，仅上传待验收产物，不自动公开发布。
